# LabourLink - Migrant Workers Management System

LabourLink is a comprehensive, web-based digital platform designed to bridge the gap between migrant workers, job seekers, recruitment agencies, and administrative authorities. Developed as a project for the Sabaragamuwa University of Sri Lanka.

---

## 🚀 Project Overview

The platform addresses the fragmentation in existing recruitment systems by offering four specialized portals:

- **Worker Portal**: Allows workers to submit complaints regarding workplace issues like salary disputes or safety concerns.
- **Job Seeker Portal**: Enables individuals to manage profiles and apply for verified job opportunities.
- **Job Agency Portal**: Provides agencies with tools to post vacancies and manage candidate applications.
- **Administrator Portal**: A central control center for vetting agencies, moderating content, and managing news updates.

---

## 🛠️ Technology Stack

The system is built using modern, enterprise-grade technologies to ensure scalability and high performance:

### Frontend
- **Framework**: React.js (v18+) & Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS

### Backend
- **Framework**: ASP.NET Core 8.0
- **API Layer**: Hybrid REST & GraphQL (HotChocolate)
- **ORM**: Entity Framework Core

### Database & Infrastructure
- **Database**: MySQL 8.0+
- **Cloud Hosting**: AWS (ECS & S3)
- **Auth**: JWT & OAuth 2.0 with Role-Based Access Control (RBAC)

---


## 🏗️ System Architecture

The project follows an Agile development methodology, delivering features incrementally through weekly sprints.

The database schema is designed for data integrity and includes entities for users, workers, job_seekers, agencies, jobs, and complaints.
